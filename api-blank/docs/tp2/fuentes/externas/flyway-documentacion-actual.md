Redgate Flyway extends DevOps to your databases to accelerate software delivery and ensure quality code so you can deploy with confidence.    From version control to continuous delivery, Flyway builds on application delivery processes to automate database deployments.

### Flyway

| **Flyway Desktop **  offers a GUI-based experience for database developers and data professionals to track changes to their database objects and manage migration scripts in version control.
| --- |
It runs on Windows, macOS, and Linux.
|
| --- |
**Flyway Command Line** runs on Windows, macOS, Linux, and is available on docker. It is primarily meant for users who wish to migrate their database from the command line and is used in CI/CD systems.

Flyway can be integrated within an application using the **API**, allowing migrations to be applied when the application starts.  ** **

### Flyway Command Line & API

The Flyway command line and API are included as part of your Flyway Desktop installer.

Flyway has the following commands at its disposal:      [Migrate](https://documentation.red-gate.com/flyway/reference/commands/migrate)  ,      [Clean](https://documentation.red-gate.com/flyway/reference/commands/clean)  ,      [Info](https://documentation.red-gate.com/flyway/reference/commands/info)  ,      [Validate](https://documentation.red-gate.com/flyway/reference/commands/validate)  ,      [Undo](https://documentation.red-gate.com/flyway/reference/commands/undo)  ,      [Baseline](https://documentation.red-gate.com/flyway/reference/commands/baseline), [Repair](https://documentation.red-gate.com/flyway/reference/commands/repair), [Check](https://documentation.red-gate.com/flyway/reference/commands/check) and [Snapshot](https://documentation.red-gate.com/flyway/reference/commands/snapshot)  .

Migrations can be written in    [SQL     ](https://documentation.red-gate.com/flyway/flyway-concepts/migrations)(native database-specific syntax such as PL/SQL and T-SQL is supported) or    [Java     ](https://documentation.red-gate.com/flyway/flyway-concepts/migrations/java-based-migrations)(for advanced data transformations or dealing with LOBs).

If you are on the JVM, we recommend using the    [Java API](https://documentation.red-gate.com/flyway/reference/usage/api-java)    for migrating the database on application startup. Alternatively, you can also use the    [Maven plugin](https://documentation.red-gate.com/flyway/reference/usage/maven-goal)    or    [Gradle Plugin](https://documentation.red-gate.com/flyway/reference/usage/gradle-task). There are [community plugins](https://documentation.red-gate.com/flyway/reference/usage/community-plugins-and-integrations)    available for Spring Boot, Dropwizard, Grails, Play, SBT, Ant, Griffon, Grunt, Ninja and more!

You can find out about [Databases the CLI supports](https://documentation.red-gate.com/flyway/reference/database-driver-reference) in the documents and the list includes [Oracle](https://documentation.red-gate.com/flyway/reference/database-driver-reference/oracle-database),    [SQL Server](https://documentation.red-gate.com/flyway/reference/database-driver-reference/sql-server-database),    [MySQL](https://documentation.red-gate.com/flyway/reference/database-driver-reference/mysql)    (plus variants), [PostgreSQL](https://documentation.red-gate.com/flyway/reference/database-driver-reference/postgresql-database) (and many variants) as well as NoSQL databases like [MongoDB](https://documentation.red-gate.com/flyway/reference/database-driver-reference/mongodb) and [Cassandra](https://documentation.red-gate.com/flyway/reference/database-driver-reference/cassandra-database).

If you are looking for whether specific databases have Foundational or Advanced support then see [Supported Databases and Versions](https://documentation.red-gate.com/flyway/getting-started-with-flyway/system-requirements/supported-databases-and-versions)
