### Source code

The source code can be found in the main [file browser](https://www.postgresql.org/ftp/source/) or you can access the source control repository directly at [git.postgresql.org](https://git.postgresql.org/gitweb/?p=postgresql.git;a=summary). Instructions for building from source can be found in the [documentation](https://www.postgresql.org/docs/current/installation.html).

### Beta/RC Releases and development snapshots (unstable)

There are source code and binary [packages](https://www.postgresql.org/download/snapshots/) of beta and release candidates, and of the current development code available for testing and evaluation of new features. Note that these builds should be used **for testing purposes only**, and not for production systems.

## Additional Software

### Software Catalogue

There is much software available that is not bundled with PostgreSQL. The [Software Catalogue](https://www.postgresql.org/download/product-categories) offers a listing of many commercial and Open Source applications, interfaces and extensions to PostgreSQL that you may find useful.

If you wish to have your product listed in the catalogue, please fill out this [form](https://www.postgresql.org/account/products/new/).

## File Browser

You can download most of the software we publish from a mirror site using our [File Browser](https://www.postgresql.org/ftp/).
